# 🧪 AI/ML Practice Lab

Hands-on exercises I'm working through while building my foundation in AI/ML — data handling, preprocessing, and visualization, one script at a time.

## 📂 What's Inside

| File | What it covers |
|---|---|
| `numpy_1.py` | Getting comfortable with NumPy arrays and operations |
| `numpy_pandas.py` | Combining NumPy + Pandas for real data workflows |
| `list_manipulation.py` | Core Python list manipulation drills |
| `data_preprocessing.py` | Cleaning and prepping data before modeling |
| `matplotlib_exercises.py` | Plotting and visualizing data with Matplotlib |
| `seaborn.py` | Statistical visualizations with Seaborn |

## ⚙️ Getting Started

```bash
git clone https://github.com/your-username/ai-ml-practice-lab.git
cd ai-ml-practice-lab
python -m venv venv
source venv/bin/activate    # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Run any file:
```bash
python numpy_1.py
```

## ⚠️ Heads Up

- `numpy_pandas.py` was originally written in Google Colab, so it has a `from google.colab import files` line — comment it out (or remove) if you're running it locally.
- `matplotlib_exercises.py` is deliberately not named `matplotlib.py` — naming it that way conflicts with the actual `matplotlib` library on import.

## 🎯 Why this repo exists

Building this as I go through my AI/ML learning path — small, focused scripts instead of one big messy notebook, so each concept is easy to find and revisit later.
